MedTerm Forge Ver 5.2 개선본

업로드용: index.html과 medterm-hq-*.js 파일들을 같은 위치에 모두 올리세요. 기존 이미지·저장 JS는 남겨도 됩니다.
통합본: index.html 하나에 이미지와 저장 코드가 모두 포함됩니다. 용량이 커서 웹 수동 업로드용으로는 권하지 않습니다.
배포 뒤 ?v=5.2-hq 로 확인하세요. 같은 사이트 주소에서는 이전 학습 기록을 유지합니다.

강의실: 현재 시험 범위·단원 필터별로 설명 묶음을 유지합니다. 정오 평가가 200회 추가되면 강의실을 열 때 갱신합니다. 읽기·시간 초과는 제외합니다. 지금 새로 구성 버튼으로 즉시 갱신할 수도 있습니다.
디자인: 세 테마의 배경·장식과 캐릭터별 여섯 색상을 확장했습니다.
그림: 교재 그림 80개를 같은 원본 PDF의 큰 해상도로 다시 추출해 무손실 WebP로 저장했습니다. 원본 스캔의 필기나 흐림 자체를 지우거나 새로 그리지는 않았습니다. 캐릭터 이미지 원본 바이트는 유지했습니다.
중요도: 원문 위치와 학습 역할을 OCR 보조 방식으로 재대조했습니다. 미확정 항목은 B 대신 U로 남겼습니다. audit-report.txt와 importance-ledger.json에서 범위와 한계를 확인할 수 있습니다. 수동 중요도는 보존합니다.
